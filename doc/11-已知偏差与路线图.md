# 11 已知偏差与路线图

本章记录“设计目标 vs 当前实现”的差异、已知问题和后续方向。改动相关代码前先阅读；确认要修实现还是改设计时，同步更新本文档与原始设计文档。

原始设计文档已移动到 [personal-system-design-v2.md](personal-system-design-v2.md)。

## 11.1 架构与机制偏差

| 项 | 设计/文档描述 | 当前实现 | 影响与建议 |
|---|---|---|---|
| 文档 ID | UUID v7（时间有序） | `uuid::Uuid::new_v4()` | 排序依赖 `updated_at`，不影响功能；如需按 ID 排序再升级 |
| 模块注册 | `public/modules.json` 注册表（含 `entryPoint`/`enabled`） | `import.meta.glob` 自动发现 `src/modules/*/index.ts`，元数据由模块实例声明 | 新增模块无需改注册文件；新增目录需重启 Vite |
| 模块搜索 | `ModuleInterface.onSearch` + 全局搜索框 | 接口已定义，`AppShell` 搜索框仍 `disabled` | 全局搜索未接入 |
| 同步方式 | 基于 `sync_operations` 的增量同步 | 全量 `documents` + `notes` 交换，按 `updated_at` 合并 | `sync_operations` 只写不读；数据量大时 payload 大 |
| 同步范围 | 设计包含全部业务数据 | 只同步文档与笔记；不含文件夹、书籍、标注 | 跨设备文件夹 ID 可能悬空；书籍/标注不同步 |
| 同步状态表 | `sync_state`、`known_devices` | 已建表，未使用 | 设备发现结果只在内存 |
| 同步端口 | `sync.port` 配置 | 硬编码 UDP 54321 / HTTP 54322 | 修改端口需要改代码 |
| 基础存储 | `platform/services/storage.ts` 统一业务封装 | 模块各自 `api.ts` 直接 invoke；`storage.ts` 未使用 | 保留待用 |
| 文件夹表 | 设计早期的 `folders` 表 | `Note_Folders`（四位编号、层级、排序、冗余父名） | 旧表启动时自动迁移并删除 |
| 删除策略 | 软删除 | 笔记/书籍/标注软删除；文件夹物理删除 | 文件夹删除不可恢复 |

## 11.2 功能实现现状

| 项 | 现状 | 说明 |
|---|---|---|
| Android | 前端/入口已适配，工程未生成 | 需要 `tauri android init` 与移动端权限验证 |
| MOBI | 可导入、可入库，不能阅读 | 打开时提示「暂不支持格式: mobi」 |
| EPUB 进度 | 只存 `localStorage` 的 CFI | 不写 `books.current_page`，书架进度显示 0 / n |
| EPUB 目录/标注 | 已实现 | 标注仅 EPUB 支持 |
| PDF/TXT 标注 | 未实现 | 无选中文本高亮 |
| PDF 中文 | 依赖 unpkg cMap | 离线环境可能缺字 |
| 封面 | `cover_url` 字段存在但未提取 | 书架使用格式占位图 |
| 标签计数 | 基于当前已加载笔记 | 切换文件夹后计数变化，不是全库统计 |
| 文件夹同步 | 未同步 | 同步后另一端的 `folder_id` 可能指向不存在的文件夹 |
| 自动同步 | 手动触发 | 设计中的定时同步未实现 |
| 身份认证 | 无 | HTTP 明文、无鉴权，仅适合可信局域网 |
| 全局搜索 | 未接入 | 模块 `onSearch` 未实现 |

## 11.3 已知问题

| 问题 | 位置 | 影响 | 建议 |
|---|---|---|---|
| PDF/TXT 方向键可能翻两页/两章 | `BookReaderView.vue` 与 `PdfReader.vue` / `TxtReader.vue` 都监听 `keydown` | 一次按键前进两步 | 只保留一处监听，或父组件只处理 EPUB |
| EPUB 阅读进度不进数据库 | `EpubReader.vue` | 书架进度、状态不准确，跨设备不同步 | 在 `relocated` 时按章节比例更新 `currentPage`，或新增 CFI 字段 |
| 删除文件夹后 UI 未刷新（历史问题） | `stores/notepad.ts` | 子文件夹显示到根级 | 已修复为删除后 `fetchFolders()`；后续改动勿回退 |
| `window.confirm` 取消仍返回 true（历史问题） | 所有删除入口 | 误删除 | 已统一改为 `confirmAction`；禁止再使用原生 confirm |
| 同步不接受相同 `updated_at` | `merge_payload` | 两端同一毫秒修改时可能保留本地 | 可加入设备 ID 或版本号作为平局裁决 |
| 标注删除不检查存在性 | `delete_annotation` | 重复删除无报错 | 可补 `affected` 检查 |
| 删除书籍不级联标注 | `delete_book` | 标注文档仍存在，但书籍列表不可见 | 如需清理，删除书籍时一并软删除标注 |
| 文件夹删除硬删除 | `delete_folder` | 无法撤销、无法同步删除 | 如需多端一致，改为软删除并纳入同步 |
| 安装/卸载可能删除数据 | NSIS `RMDir /r "$INSTDIR"` + exe 目录数据 | 管理员运行且数据在安装目录时被删 | 卸载前备份；或把发布数据固定到 AppData |

## 11.4 质量与工程化

| 项 | 现状 | 建议 |
|---|---|---|
| 自动化测试 | 无 | 优先为文件夹迁移、删除移动、同步合并补 Rust 单元测试 |
| Lint/格式化 | 无 | 引入 ESLint + Prettier + rustfmt/clippy |
| CI | 无 | 至少执行 `pnpm build` + `cargo check` + `cargo clippy` |
| 数据库迁移 | 只有启动时 `CREATE IF NOT EXISTS` 与专用迁移函数 | 引入 `user_version` 或迁移表，按版本执行 |
| 日志 | 单文件按天、无轮转上限 | 增加保留天数/大小清理 |
| 错误提示 | 直接展示后端字符串 | 可做错误码与本地化 |

## 11.5 安全与隐私

- 同步服务绑定 `0.0.0.0:54322`，无认证、无 TLS；同一局域网内任何人都可请求 `/api/info` 与 `/api/sync/exchange`。
- 建议仅在可信私有网络使用；后续可加入共享密钥、HMAC 签名或 TLS。
- `read_book_file` 可读取任意路径文件；虽然前端未开放任意调用，但命令本身没有路径限制。若暴露给不可信输入，应增加白名单。
- `delete_book_file` 已限制在 `data/books` 内。
- 日志可能包含笔记标题、书籍名、标注文本预览，注意日志目录的访问权限。

## 11.6 路线图

### P0：正确性与数据一致性

1. 修复 PDF/TXT 方向键重复处理。
2. EPUB 阅读进度写入数据库（或增加 CFI 字段），书架进度准确。
3. 同步覆盖文件夹（至少保证 `folder_id` 目标存在），或同步时进行文件夹映射。
4. 为文件夹删除/迁移、同步合并增加自动化测试。

### P1：同步与体验

1. 基于 `sync_operations` 的增量同步，减少 payload。
2. 同步鉴权与可配置端口（让 `sync.port` 生效）。
3. 全局搜索接入（模块 `onSearch` + 顶栏搜索框）。
4. 导入时提取 EPUB 封面与元数据（作者、封面）。
5. PDF/TXT 标注支持。
6. 同步冲突可视化与手动选择。

### P2：平台与工程化

1. 生成并验证 Android 工程（文件选择、网络权限、后台生命周期）。
2. 数据库版本化迁移。
3. ESLint/Prettier/clippy/CI。
4. 日志轮转与诊断包导出。
5. 主题/深色模式、字体大小设置。
6. 数据导入导出（Markdown/JSON 备份）。
