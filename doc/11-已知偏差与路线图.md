# 11 已知偏差与路线图

本章记录“设计目标 vs 当前实现”的差异、已知问题和后续方向。改动相关代码前先阅读；确认要修实现还是改文档时，同步更新本文档。

原始设计文档 `personal-system-design-v2.md` 已不再作为参考，归档在 [`backup/_2026102201/`](backup/_2026102201/)，仅用于追溯设计意图。

## 11.1 架构与机制偏差

| 项 | 设计/文档描述 | 当前实现 | 影响与建议 |
|---|---|---|---|
| 文档 ID | UUID v7（时间有序） | `uuid::Uuid::new_v4()` | 排序依赖 `updated_at`，不影响功能；如需按 ID 排序再升级 |
| 模块注册 | `public/modules.json` 注册表（含 `entryPoint`/`enabled`） | `import.meta.glob` 自动发现 `src/modules/*/index.ts`，元数据由模块实例声明 | 新增模块无需改注册文件；新增目录需重启 Vite |
| 模块搜索 | `ModuleInterface.onSearch` + 全局搜索框 | 接口已定义，`AppShell` 搜索框尚未接入 | 全局搜索未接入 |
| 文件夹表 | 设计早期的 `folders` 表 | `Note_Folders`（四位编号、层级、排序、冗余父名）；笔记表为独立的 `Note_Content` | 旧 `folders` / `notes` 表启动时自动迁移并删除 |
| 阅读器表 | 设计早期的 `documents` + `books` / `annotations` | 独立的 `Read_Books` / `Read_Annotation`（十位编号、PascalCase 字段） | 旧表启动时自动迁移并删除 |
| 删除策略 | 软删除 | 笔记/书籍/标注软删除（删除书籍级联软删标注）；文件夹物理删除 | 文件夹删除不可恢复 |
| 业务 ID | UUID | 笔记/书籍/标注均为十位补零自增编号（`0000000001` 起），文件夹四位编号 | 各设备独立计数，跨设备不保证唯一 |

## 11.2 功能实现现状

| 项 | 现状 | 说明 |
|---|---|---|
| Android | 前端/入口已适配，工程未生成 | 需要 `tauri android init` 与移动端权限验证 |
| MOBI | 可导入、可入库，不能阅读 | 打开时提示「暂不支持格式: mobi」 |
| EPUB 进度 | 只存 `localStorage` 的 CFI | 不写 `Read_Books.Current_Page`，书架进度显示 0 / n |
| EPUB 目录/标注 | 已实现 | 标注已与 PDF/TXT 统一 |
| PDF/TXT 标注 | 已实现 | PDF 使用文本层选区 + 归一化矩形高亮，TXT 使用章节内字符偏移 |
| PDF 中文 | 依赖 unpkg cMap | 离线环境可能缺字 |
| 封面 | `Cover_Url` 字段存在但未提取 | 书架使用格式占位图 |
| 标签计数 | 基于当前已加载笔记 | 切换文件夹后计数变化，不是全库统计 |
| 全局搜索 | 未接入 | 模块 `onSearch` 未实现 |

## 11.3 已知问题

| 问题 | 位置 | 影响 | 建议 |
|---|---|---|---|
| PDF/TXT 方向键可能翻两页/两章 | 已修复 | `BookReaderView.vue` 统一处理键盘，`PdfReader`/`TxtReader` 不再监听 | 后续改动勿在子组件重新加 `keydown` |
| EPUB 阅读进度不进数据库 | `EpubReader.vue` | 书架进度、状态不准确 | 在 `relocated` 时按章节比例更新 `currentPage`，或新增 CFI 字段 |
| 删除文件夹后 UI 未刷新（历史问题） | `stores/notepad.ts` | 子文件夹显示到根级 | 已修复为删除后 `fetchFolders()`；后续改动勿回退 |
| `window.confirm` 取消仍返回 true（历史问题） | 所有删除入口 | 误删除 | 已统一改为 `confirmAction`；禁止再使用原生 confirm |
| 文件夹删除硬删除 | `delete_folder` | 无法撤销 | 如需可恢复，改为软删除 |
| 安装/卸载可能删除数据 | NSIS `RMDir /r "$INSTDIR"` + exe 目录数据 | 管理员运行且数据在安装目录时被删 | 卸载前备份；或把发布数据固定到 AppData |

## 11.4 质量与工程化

| 项 | 现状 | 建议 |
|---|---|---|
| 自动化测试 | 无 | 优先为文件夹迁移、删除移动、阅读器表迁移补 Rust 单元测试 |
| Lint/格式化 | 无 | 引入 ESLint + Prettier + rustfmt/clippy |
| CI | 无 | 至少执行 `pnpm build` + `cargo check` + `cargo clippy` |
| 数据库迁移 | 只有启动时 `CREATE IF NOT EXISTS` 与专用迁移函数 | 引入 `user_version` 或迁移表，按版本执行 |
| 日志 | 单文件按天、无轮转上限 | 增加保留天数/大小清理 |
| 错误提示 | 直接展示后端字符串 | 可做错误码与本地化 |

## 11.5 安全与隐私

- `delete_book_file` 已限制在 `data/books` 内。
- 日志可能包含笔记标题、书籍名、标注文本预览，注意日志目录的访问权限。

## 11.6 路线图

### P0：正确性与数据一致性

1. EPUB 阅读进度写入数据库（或增加 CFI 字段），书架进度准确。
2. 为文件夹删除/迁移、阅读器表迁移增加自动化测试。

### P1：体验与功能

1. 全局搜索接入（模块 `onSearch` + 顶栏搜索框）。
2. 导入时提取 EPUB 封面与元数据（作者、封面）。
3. ~~PDF/TXT 标注支持~~（已完成，见 11.2）。

### P2：平台与工程化

1. 生成并验证 Android 工程（文件选择、网络权限、后台生命周期）。
2. 数据库版本化迁移。
3. ESLint/Prettier/clippy/CI。
4. 日志轮转与诊断包导出。
5. 主题/深色模式、字体大小设置。
6. 数据导入导出（Markdown/JSON 备份）。
