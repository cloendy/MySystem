### 2026-10-23 笔记表重构

- `notes` 表替换为独立的 `Note_Content`，不再写入 `documents`：
  - `Note_ID VARCHAR(10)` 十位补零自增主键（`0000000001` 起）；
  - `Note_Title VARCHAR(20)`、`Note_Content`、`Tags`、三个毫秒时间字段；
  - `Is_Folder` + `Folder1~3` 冗余文件夹路径，`Is_Pinned CHAR(1)`；
  - `Device_ID` 记录最后写入设备，`Version` 创建时为 1、更新/删除 +1。
- 启动迁移：旧 `notes` + `documents(type='note')` 数据重新编号后写入 `Note_Content`，随后先 `DROP TABLE notes` 再删除 `documents` 中 `type='note'` 的行（旧表外键引用 `documents`，顺序反了会触发外键约束失败）；超长标题截断并写警告日志。
- `ensure_note_content_columns` 在启动时用 `PRAGMA table_info` 检查并补齐旧库缺失的 `Device_ID` / `Version` 列。
- 文件夹操作适配新表：删除文件夹时按层级精确移动笔记，并由 `refresh_note_paths` 重建路径。
- 新增笔记「⋯」菜单「置顶/取消置顶」（位于「移动」上方）。

### 2026-10-23 笔记保存机制

- 编辑页改为基于快照的脏检查（`savedTitle` / `savedContent`）：打开或浏览笔记不产生写库，状态显示「已保存」。
- 有修改时停止输入 5 秒自动保存（原 800ms 防抖），持续编辑每 30 秒强制保存一次。
- 离开编辑页（返回、文件夹树跳转、路由后退）与关闭窗口前各保存一次；未修改则跳过，关闭流程不会因保存卡住。
- 多次保存通过 Promise 链串行化，避免后发起的保存被先发起的覆盖；删除中的笔记不再触发保存。
- 保存状态文案增加「未保存」；`capabilities/default.json` 增加 `core:window:allow-close` 以支持关闭前保存。

### 数据与文件夹

- 文件夹表由 `folders` 改为 `Note_Folders`：
  - 四位补零编号 `Folder_ID`，最大 9999；
  - 显式 `Folder_Level`（0 为默认「未命名」，1–3 为用户层级）；
  - `Folder_Parent_ID` / `Folder_Parent_Name` / `Folder_Order`；
  - 唯一索引保证同级不重名。
- 启动时自动迁移旧 `folders` 表并删除旧表，同步重映射 `notes.folder_id`。
- 默认文件夹改为固定编号 `0001 / 未命名 / 层级 0 / 排序 0`；不可改名、删除或添加子文件夹。
- 删除文件夹时：
  - 笔记移动到父文件夹（根级删除时进入「未命名」）；
  - 子文件夹上移一级并追加排序；
  - 子文件夹重名时改名为 `原名_folder_被删文件夹名`，必要时追加序号；
  - 后代层级递归调整。
- 文件夹重命名改为内联输入框，Enter/失焦提交，Esc 取消，空名/同名不修改。

### 2026-10-30 JSON 分析模块

- 新增第三个业务模块 `jsonview`（前端 `src/modules/jsonview/`，Rust `src-tauri/src/modules/jsonview/`）：

  - 点击「分析」后以树形结构展示对象、数组与基本值，字段包括键名、类型、值预览、JSONPath 路径；

  - 支持展开/折叠全部与 Ctrl + Enter 快捷分析；不写入数据库。
- 新增 Rust 命令 `read_json_file`（读取 UTF-8 文本、去 BOM、限制 10 MB），已在 `commands.rs` 注册。

### 2026-10-30 阅读器表重构与三格式标注

- `documents` + `books` + `annotations` 重构为独立的 `Read_Books` / `Read_Annotation`：
  - `Book_ID` / `Annotation_ID` 为十位补零自增主键（`0000000001` 起）；
  - PascalCase 字段、`Create_Time` / `Update_Time` / `Delete_Time`、`Device_ID` / `Version`；
  - 时间列使用 `DATETIME` 类型，存 UTC 文本（`YYYY-MM-DD HH:MM:SS.mmm`），字符串排序即时间排序；旧表的毫秒时间戳迁移时转换为该格式，Rust 结构体与前端类型同步改为 `String` / `string`；
  - 表名由中间版本 `Book_Content` / `Annotation_Content` 调整为 `Read_Books` / `Read_Annotation`，索引相应改为 `idx_read_books_hash`、`idx_read_books_list`、`idx_read_annotation_book`；两张表的测试数据已清空；
  - `Book_Hash CHAR(64)` 保存源文件 SHA-256，用于导入去重；
  - 启动时 `modules::reader::init()` 把旧表数据按 `created_at` 重新编号后迁移，单事务内依次 `DROP annotations` → `books` → `documents`，失败回滚并在下次启动重试。
- 删除书籍改为同事务级联软删除其标注；`delete_annotation` 增加影响行数检查。
- 导入去重：`import_book_file` 流式计算 SHA-256，命中未删除的同哈希书籍时不复制文件，返回 `{ hash, duplicate: true, existing }`；书架弹三选一（打开已有 / 仍然导入 / 取消，使用新增的 `ChoiceDialog.vue` + `chooseAction`）。
- TXT 章节解析抽到 `modules/reader/utils/txt.ts`，导入与阅读器共用 `decodeText` / `parseChapters` / `countChapters`，修复导入 `totalPages`（912）与阅读器章节数（504）不一致；打开旧 TXT 时自动回写修正后的章节数。
- 三格式标注统一：
  - `AnnotationPanel` 的跳转/删除事件改为携带完整 `Annotation`，由 `BookReaderView` 按格式转发；
  - PDF 新增文本层（pdfjs `TextLayer`）与高亮层，选区按页面归一化矩形保存，缩放/切页后仍可定位；
  - TXT 新增选区与章节内字符偏移高亮（`{chapter,start,end,text}`），支持重叠标注；
  - EPUB 保持 CFI 方案，仅包装为统一的 `jumpToAnnotation` / `removeAnnotationHighlight`。
- 阅读器工具栏统一为「返回 / 目录 / 标注 / 书名 / 格式专属 / 进度 / 翻页」，键盘监听收敛到 `BookReaderView` 一处，修复方向键翻两页/两章。

## 0.1.0 — 初始可用版本

### 平台

- Tauri 2 + Vue 3 + TypeScript + Vite 工程骨架。
- 平台/模块分层：`src/platform` 与 `src/modules`。
- 模块自动发现（`import.meta.glob`）、路由自动注册（`/{moduleId}` 前缀）。
- Windows `AppShell` 与 Android `MobileShell` 双外壳。
- 统一数据目录 `<应用根>/data`：`mydata.db`、`books/`、`log/`。
- 统一日志服务：Rust `log_*!` 宏 + 前端 `logger`，按天分文件，设置页可查看。
- 全局 UI 点击日志与路由切换日志。

### 记事本

- 笔记 CRUD、软删除、置顶、标题/内容搜索。
- Markdown/纯文本双模式编辑（CodeMirror 6 + marked 预览），自动保存。
- 嵌套文件夹（最多 3 层）、内联新建/重命名、删除上移。
- 标签增删、标签筛选与计数。
- 笔记移动菜单。

### 阅读器

- EPUB/PDF/TXT 阅读；MOBI 可导入但暂不支持阅读。
- EPUB 目录、CFI 位置记忆、选中高亮标注、标注面板。
- PDF 分页渲染、缩放、进度保存与恢复。
- TXT 编码识别、章节解析、目录、跳章、进度保存。
- 书架导入、状态筛选、进度展示、删除。

### 数据

- 统一基表 `documents` + 扩展表 `notes`、`books`、`annotations`。
- `app_config` 键值配置表建表。
