# 09 部署与配置

## 9.1 Tauri 配置（`src-tauri/tauri.conf.json`）

| 配置 | 值 | 说明 |
|---|---|---|
| `productName` | `mysystem` | 产品名 |
| `version` | `0.1.0` | 与 `package.json`、`Cargo.toml` 保持一致 |
| `identifier` | `com.mysystem.app` | 应用标识 |
| `build.beforeDevCommand` | `pnpm dev` | 开发前启动 Vite |
| `build.devUrl` | `http://localhost:1420` | 固定端口 |
| `build.beforeBuildCommand` | `pnpm build` | 打包前类型检查 + 构建 |
| `build.frontendDist` | `../dist` | 前端产物 |
| `app.windows[0]` | 1200×800，标题 `mysystem` | 默认窗口 |
| `app.security.csp` | 见下 | 内容安全策略 |
| `bundle.targets` | `nsis` | 仅 Windows 安装包 |
| `bundle.windows.nsis.template` | `windows/installer.nsi` | 自定义安装脚本 |
| `bundle.windows.nsis.installMode` | `perMachine` | 安装到 Program Files |

### CSP

```
default-src 'self';
img-src 'self' asset: http://asset.localhost https://act-webstatic.mihoyo.com;
style-src 'self' 'unsafe-inline';
script-src 'self' 'unsafe-inline'
```

- 允许 asset 协议加载本地书籍/封面；
- 允许角色图鉴加载 `https://act-webstatic.mihoyo.com` 的角色/装备图标（离线时前端回退为首字头像）；
- 允许内联样式与脚本（Vue/CodeMirror 需要）；
- 未显式设置 `connect-src`，会回退到 `default-src 'self'`；PDF 组件远程加载 cMap（unpkg）可能因此被 CSP 拦截。若中文 PDF 缺字或控制台出现 CSP 报错，应改为本地 cMap，或在 CSP 中显式加入 `connect-src https://unpkg.com`。

### asset 协议

`assetProtocol.enable = true`，静态 scope 包含：

- `D:\wgl\**`
- `$APPDATA\**`
- `$APPDATA/**`

运行时 `lib.rs` 还会动态授权 `<data>` 目录，保证导入的书籍可被 `convertFileSrc` 读取。

## 9.2 权限（`src-tauri/capabilities/default.json`）

```json
{
  "windows": ["main"],
  "permissions": [
    "core:default",
    "dialog:default",
    "dialog:allow-open"
  ]
}
```

- `dialog`：打开文件选择、统一确认框；
- 新增 Tauri 插件/API 时必须同步添加权限，否则运行时会拒绝。

## 9.3 构建与打包

### 开发

```bash
pnpm tauri dev
```

流程：`beforeDevCommand` 启动 Vite（1420）→ 编译 Rust → 打开窗口。

### 发布

```bash
pnpm tauri build
```

流程：`pnpm build`（`vue-tsc --noEmit` + Vite）→ Rust release 编译 → 调用 NSIS 模板生成安装包。

产物：

- Tauri 打包的安装包通常位于 `src-tauri/target/release/bundle/nsis/`；
- 可执行文件为 `src-tauri/target/release/mysystem.exe`；
- 本仓库的自定义模板里写了 `OutFile "nsis-output.exe"`；如果直接用 `makensis` 执行该模板，输出位置以命令行为准。

### 自定义 NSIS 模板

`src-tauri/windows/installer.nsi`：

- 安装目录 `$PROGRAMFILES64\MySystem`；
- 复制 `dist\*.*` 与 `target\release\mysystem.exe`；
- 创建桌面快捷方式、开始菜单项、卸载快捷方式；
- 简体中文界面；
- 卸载时 `RMDir /r "$INSTDIR"` 递归删除安装目录。

> ⚠️ 卸载会递归删除安装目录。发布模式下数据目录默认是 **exe 所在目录/data**，如果应用以管理员权限运行并成功写入安装目录，`data/` 也会被卸载删除。卸载/升级前请备份 `data/`。

## 9.4 数据目录

| 场景 | 路径 |
|---|---|
| 开发（`tauri dev`） | 项目根 `data/` |
| 发布，exe 目录可写 | `exe 所在目录/data` |
| 发布，exe 目录不可写 | `app_data_dir()/data`（通常是 `%APPDATA%/<identifier>/data`） |
| Android | 应用私有数据目录 `/data` |
| 环境变量 `MYSYSTEM_DATA_DIR` | 覆盖以上所有规则 |

说明：

- Windows `perMachine` 安装到 `Program Files`，普通用户通常无写权限，因此发布版很可能回退到 `%APPDATA%`。
- 判断可写的方式是尝试创建目录并写 `.write_test` 文件。
- 数据库、书籍、日志的位置见 [05-数据库设计.md](05-数据库设计.md)。

## 9.5 网络端口与防火墙

| 协议 | 端口 | 用途 | 说明 |
|---|---|---|---|
| TCP | 1420 | Vite 开发服务器 | 仅开发 |
| TCP | 54322 | 同步 HTTP 服务端 | `GET /api/info`、`POST /api/sync/exchange` |
| UDP | 54321 | 局域网发现 | 广播 `discover` / 回复 `announce` |

- 端口当前硬编码，`CONFIG_KEYS.SYNC_PORT` 未生效。
- Windows 防火墙可能拦截入站；首次开启同步时应允许私有网络访问。
- 两台设备需在同一局域网，且未启用 AP 隔离/VLAN 隔离。
- 同步服务绑定 `0.0.0.0`，请只在可信局域网使用。

## 9.6 应用配置

配置存放在数据库 `app_config` 表：

| 键 | 值 | 何时写入 |
|---|---|---|
| `sync.receive.enabled` | `'true'` / `'false'` | 设置页切换开关 |
| `device.name` | 文本 | 设置页修改设备名 |
| `sync.port` | 未使用 | — |

启动时只有进入设置页才会读取并恢复同步服务（`useSyncSettings.initSyncSettings`）。若希望开机自动同步，需要在应用启动时也调用初始化逻辑。

## 9.7 Android 现状

- 前端已按 `detectPlatform()` 区分外壳和布局；
- Rust 入口已加 `#[cfg_attr(mobile, tauri::mobile_entry_point)]`；
- 数据目录在 Android 上使用 `app_data_dir()/data`；
- **`src-tauri/gen/android` 尚未生成**，需要执行 Tauri 的 Android 初始化与构建流程（安装 Android Studio/SDK/NDK，`pnpm tauri android init` / `android dev`）；
- 部分能力（文件选择、同步端口绑定、后台运行）在 Android 上需要额外权限与生命周期处理，尚未验证。

## 9.9 备份与迁移

- 备份：退出应用后复制整个 `data/`；如存在 `mydata.db-wal` / `mydata.db-shm`，一并复制。
- 迁移到新机器：复制 `data/` 到新机器的对应数据目录；书籍路径是绝对路径，若目录变化需要更新 `Read_Books.File_Path`。
- 恢复：退出应用，替换 `data/` 后重启；启动时会自动建表并检查默认文件夹。
