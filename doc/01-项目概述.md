# 01 项目概述

## 1.1 项目是什么

MySystem 是一个**个人跨平台系统**，使用同一套前端代码运行在 Windows（PC 主机）和 Android（客户端）上。系统由平台外壳和可插拔的业务模块组成，数据保存在本地 SQLite，各端数据独立，不依赖中心服务器。

当前版本：`0.1.0`。桌面端可用；Android 工程尚未生成，但代码已按平台做了适配预留。

## 1.2 核心需求

| 编号 | 需求 | 当前实现 |
|---|---|---|
| R1 | 同一套代码运行在 Windows 和 Android | Windows 已实现；Android 代码适配完成，工程未生成 |
| R2 | 多端数据通过局域网保持一致 | 暂未实现；局域网同步子系统已于 2026-10-30 整体移除，各端数据独立 |
| R3 | 平台外壳 + 可插拔模块 | 已实现模块自动发现、路由自动注册、双端外壳 |
| R4 | 首批模块：记事本、阅读器 | 均已实现；另新增 JSON 分析、角色图鉴模块 |
| R5 | 无中心服务器，PC 作为主机 | 当前为本地单机架构，无中心服务器 |
| R6 | 使用 VS Code 开发 | 已提供 VS Code 推荐扩展配置 |

## 1.3 已实现的能力

### 记事本（notepad）

- Markdown / 纯文本编辑，CodeMirror 6 编辑区 + Markdown 实时预览。
- 自动保存（有修改时停止输入 5 秒后写库，持续编辑每 30 秒强制保存；离开页面或关闭窗口前保存一次，未修改不写库）。
- 嵌套文件夹：最多 3 层，支持内联新建、内联重命名、删除与子级上移。
- 标签：添加/删除标签、按标签筛选、标签计数。
- 置顶、标题/内容搜索、笔记移动与删除。
- 默认文件夹「未命名」（固定编号 `0001`）。
- 旧版 `folders` 表启动时自动迁移到 `Note_Folders`。

### 阅读器（reader）

- 导入 EPUB / PDF / TXT / MOBI 文件（MOBI 可入库，但暂不能阅读）。
- EPUB：章节目录、CFI 位置记忆、文本选中高亮标注、标注跳转/删除。
- PDF：分页渲染、缩放、键盘翻页、进度保存。
- TXT：章节自动识别、目录、跳章、编码自动识别（UTF-8/UTF-16/GBK）、进度保存。
- 书架状态筛选（全部/在读/未读/已读完）与阅读进度展示。

### JSON 分析（jsonview）

- 导入本地 `.json` / `.txt` 文件（UTF-8，最大 10 MB），或直接粘贴 JSON 文本。
- 点击「分析」后用树形结构展示对象/数组/基本值，每行显示键名、类型、值预览与 JSONPath 路径。
- 汇总统计：根类型、节点总数、最大层级、对象/数组/基本值数量。
- 解析失败时提示行列位置；超大结构按上限截断（单节点 100 个子项、总计 5000 个节点、最大 50 层），并标注「已截断」。
- 支持展开全部 / 折叠全部、Ctrl + Enter 快捷分析；不写入数据库。

### 角色图鉴（ys）

- 每次进入页面读取 `data/其他/ys.json`，按 `设定.txt` 的字段说明展示角色列表；文件缺失时显示「没有找到 ys.json」。
- 列表显示角色头像、名称、元素、武器类型、星级、等级、装备武器，以及可升级技能的名称与等级（等级上限为 1 的被动技能不显示）；展开可查看技能、武器、圣遗物明细。
- 快捷筛选：角色/武器/技能/圣遗物关键词、元素、武器类型、星级、等级范围（技能关键词只匹配可升级技能）。
- 固定筛选按钮「任一技能 < 9」：筛出三个可升级技能中至少一个低于 9 级的角色；固定条件不占用自定义条件，并与快捷/自定义条件同时满足。
- 自定义筛选：选择字段（元素、等级、命座、好感、武器、技能、圣遗物等 18 个字段，含「技能等级（任一）」）与运算符（等于/包含/大于等），支持多条件「满足全部 / 满足任一」。
- 条件设置后点击「筛选」才生效；没有有效条件时点击显示全部角色。
- 只读展示，不写入数据库；修改 JSON 后重新打开即可刷新。

### 设置

- 系统日志查看：按天分文件、级别筛选、只读尾部 512KB。
- 关于：显示应用名称与版本。

## 1.4 技术栈

| 层 | 技术 | 说明 |
|---|---|---|
| 桌面/移动容器 | Tauri 2 | Rust 后端 + 系统 WebView |
| 前端框架 | Vue 3.5（`<script setup>`） | Composition API |
| 语言 | TypeScript 6 / Rust（edition 2024） | 严格模式 `strict: true` |
| 构建 | Vite 8 | 开发端口固定 1420 |
| 状态管理 | Pinia 4 | 每个模块一个 store |
| 路由 | vue-router 4（hash 模式） | 模块路由自动加前缀 |
| 数据库 | SQLite（rusqlite） | 单文件 `data/mydata.db` |
| 编辑器 | CodeMirror 6 + `@codemirror/lang-markdown` | 纯文本模式不加载 MD 扩展 |
| Markdown 渲染 | marked | 预览区 |
| EPUB | epubjs 0.3.x | CFI 定位与高亮 |
| PDF | pdfjs-dist 6.x | Canvas 渲染 |
| 对话框 | `@tauri-apps/plugin-dialog` | 统一二次确认与文件选择 |

包管理器为 **pnpm**（仓库有 `pnpm-lock.yaml`）。

## 1.5 快速开始

### 环境要求

- Node.js（建议 20+）与 pnpm
- Rust 工具链（stable）
- Windows：WebView2 Runtime、Tauri 所需 C++ 构建工具
- 首次运行会下载前端与 Rust 依赖

### 启动

```bash
pnpm install
pnpm tauri dev      # 编译 Rust 并启动桌面应用（内部会先启动 Vite）
```

只调前端样式时可以：

```bash
pnpm dev            # 仅 Vite，端口 1420；Tauri API 不可用
```

### 构建与检查

```bash
pnpm build          # vue-tsc --noEmit + vite build
pnpm tauri build    # 生成 Windows NSIS 安装包
cd src-tauri && cargo check
```

### 数据位置

开发模式：项目根目录 `data/`；发布模式：exe 所在目录 `data/`；Android：应用私有目录 `data/`。可用环境变量 `MYSYSTEM_DATA_DIR` 覆盖。详见 [05-数据库设计.md](05-数据库设计.md)。

## 1.6 仓库结构速览

```
MySystem/
├── doc/                    # 本文档中心
├── src/                    # 前端
│   ├── platform/           # 平台外壳与基础服务（不含业务）
│   ├── modules/            # 业务模块（notepad、reader、jsonview、ys）
│   ├── styles/             # 全局共享样式
│   ├── App.vue / main.ts
├── src-tauri/              # Rust 后端
│   ├── src/platform/       # 平台基础服务
│   ├── src/modules/        # 业务模块 Rust 实现
│   ├── src/commands.rs     # 全部命令注册
│   ├── capabilities/       # Tauri 权限
│   └── tauri.conf.json
├── data/                   # 运行时数据（数据库、书籍、日志）
├── package.json / vite.config.ts / tsconfig*.json
└── CLAUDE.md               # 面向 AI 助手的项目说明
```

## 1.7 术语表

| 术语 | 含义 |
|---|---|
| 平台（platform） | 与业务无关的外壳、路由、日志、配置等基础能力 |
| 模块（module） | 自包含的业务功能包，实现 `ModuleInterface`，放进 `src/modules/` 即被发现 |
| 文档（document） | 设计早期的统一基表，已移除；笔记、书籍、标注分别使用独立表 |
| 业务编号 | `Note_ID` / `Book_ID` / `Annotation_ID` 为十位补零自增编号，`Folder_ID` 为四位 |
| 全部笔记 | 文件夹树的虚拟根，不对应数据库记录；`folder_id = null` 时表示不筛选 |
| 未命名 | 默认文件夹，固定 `Folder_ID = 0001`、层级 0，不可改名/删除 |
| CFI | EPUB Canonical Fragment Identifier，epubjs 用于定位与高亮 |
| 软删除 | 只写 `Delete_Time`，查询统一过滤 `Delete_Time IS NULL` |
