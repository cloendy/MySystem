# 03 功能设计

本章描述用户可见行为与业务规则。接口字段与数据库细节见 [06-数据结构.md](06-数据结构.md)、[07-开发API.md](07-开发API.md)、[05-数据库设计.md](05-数据库设计.md)。

## 3.1 记事本模块

### 3.1.1 笔记列表

入口：`/notepad/`（`NoteListView.vue`）。

- 左侧为文件夹树（Windows）；Android 不显示文件夹树，只能看当前筛选结果。
- 顶部工具栏：
  - 搜索框：输入后 250ms 防抖调用后端 `search_notes`，匹配标题或内容（SQL `LIKE %keyword%`）；
  - 「清空」按钮：清空关键词与搜索结果；
  - 「+ 新建笔记」：创建标题为「新笔记」、内容为空的笔记，文件夹取当前文件夹；在「全部笔记」下创建时放入「未命名」（`0001`），随后跳转编辑页。
- 标签筛选条（Windows）：展示当前已加载笔记的标签及数量，点击筛选，再点「全部」清除。
- 标题区显示当前上下文：`全部笔记`、文件夹名、`文件夹名 · #标签` 或 `搜索：关键词`。
- 列表排序：
  - 搜索中：直接使用后端返回顺序（置顶优先、更新时间倒序）；
  - 普通：置顶优先，其次 `updatedAt` 倒序；
  - 标签筛选只影响展示，不重新请求后端。
- 列表项展示：置顶图标、标题（空标题显示「无标题」）、正文首个非空行前 50 字、标签、时间（当天显示 `HH:mm`，否则 `YYYY-MM-DD`）。
- 每项右侧「⋯」打开浮动菜单：
  - 「移动」→ 展开文件夹树（缩进显示层级），当前文件夹禁用并标记「当前」；
  - 「删除」→ 二次确认后软删除。
  - 移动/删除后，若处于搜索则重新搜索，否则在具体文件夹下刷新列表。
- 空状态：搜索无结果显示「没有匹配的笔记」；普通为空显示「还没有笔记」。
- 监听 `mysystem:sync-completed`，同步完成后刷新笔记与文件夹。

### 3.1.2 笔记编辑

入口：`/notepad/edit/:id`（`NoteEditView.vue`）。

- 加载笔记失败（不存在/已删除）时提示并返回列表。
- 工具栏：返回、标题输入框、保存状态（`保存中...` / `未保存` / `已保存`）、删除。
- 标签行：`TagEditor`，可添加/删除标签；右侧插槽放置编辑模式切换。
- 编辑模式：
  - `Markdown`：CodeMirror 加载 Markdown 语法扩展，右侧显示 marked 渲染预览；
  - `纯文本`：不加载 Markdown 扩展，编辑区占满宽度，不显示预览。
  - 模式保存在 `localStorage` 键 `mysystem_notepad_editor_mode`，切换时重建编辑器，内容不丢失。
- 自动保存（脏检查 + 防抖）：
  - 以加载/上次成功保存时的标题与正文为快照，内容与快照一致时不写库，仅打开或浏览不会产生更新；
  - 有实际修改时，停止输入 5 秒后保存一次；持续编辑时每 30 秒强制保存一次；
  - 离开编辑页（返回按钮、文件夹树跳转、浏览器后退）与关闭窗口前各保存一次，未修改则跳过；
  - 多次保存串行执行，保证后发起的保存不会先落库；状态依次显示 `未保存` → `保存中...` → `已保存`。
- 删除：二次确认后软删除并返回列表。
- Windows 端左侧显示 `FolderTree`：
  - 点击文件夹先执行一次保存，再切换文件夹并跳回列表；
  - 点击「全部笔记」同样保存并返回列表。

### 3.1.3 文件夹

实现：前端 `components/FolderTree.vue` + `folders.ts`，后端 `modules/notepad/folders.rs`，表 `Note_Folders`。

#### 层级与命名

- 虚拟根「全部笔记」不对应数据库记录；其下文件夹层级为 1。
- 最多 3 层（`全部笔记/A/B/C`），层级 3 之下不能再建子文件夹。
- 默认文件夹「未命名」：`Folder_ID = 0001`、`Folder_Level = 0`、`Folder_Order = 0`；不可改名、不可删除、不可在其下建子文件夹。
- 同级文件夹不允许重名（前后端都校验）；不同父级可以同名。
- 名称去首尾空格后不能为空，最多 20 个字符。

#### 新建

- 根级：点「全部笔记」右侧「＋」；子级：点文件夹右侧「＋」（达到最大层级或默认文件夹不显示该按钮）。
- 新建为内联输入框，插入到新文件夹将出现的位置：
  - 根级追加到所有根级文件夹之后；
  - 子级插入到父文件夹当前可见子孙末尾。
- 输入框自动聚焦并全选；Enter 提交，Esc 取消，失焦提交。
- 空名称视为取消；同级重名显示「同级已存在同名文件夹」，不关闭输入框。
- 成功创建后关闭输入框；父文件夹自动展开。

#### 重命名

- 点文件夹右侧「✎」，文件夹名位置变为文本框，预填原名；不弹窗。
- Enter/失焦提交，Esc 取消。
- 名称为空或与原名相同：直接取消，不发请求。
- 同级重名：显示错误并保持编辑状态。
- 默认文件夹不可重命名。

#### 删除

- 点「✕」后使用统一确认弹窗：
  - 有父级：`确定删除文件夹「X」？其中的笔记和子文件夹会移动到「父级」。`
  - 根级：`确定删除文件夹「X」？其中的笔记会移动到「未命名」，子文件夹会保留在「全部笔记」下。`
- 删除后：
  - 该文件夹下的笔记移动到其父文件夹；删除的是根级文件夹时移到「未命名」；
  - 子文件夹上移一级，成为被删文件夹同级的节点；删除根级文件夹时子文件夹变为根级；
  - 子文件夹追加到新父级末尾，层级整体上移（其所有后代的 `Folder_Level` 递归减 1）；
  - 若上移后与同级重名，改名为 `原名_folder_被删文件夹名`；仍冲突则截断到 20 字符并追加 `(2)`、`(3)`…；
  - 前端删除后必须重新拉取文件夹（`fetchFolders`），否则本地缓存仍保留旧的 `parentId`，树会把孤儿节点当作根节点显示。
- 若当前选中的文件夹被删除，自动切回「全部笔记」并刷新笔记列表。

#### 树构建与展示

`folders.ts` 的 `buildFolderTree`：

- 根据 `parentId` 计算层级（不依赖后端顺序）；
- 父节点不存在、自引用或出现环时按根级处理，层级记为 1；
- 同级按 `sortOrder` 升序，再按名称排序；
- `未命名` 排序为 0，因此始终排在同级最前。
- 展开状态保存在组件内 `Set<string>`；有子节点的行显示 `▸/▾`。

### 3.1.4 标签

- 标签是字符串数组，数据库以 JSON 字符串存储。
- 编辑页可添加/删除标签；重复标签不添加；空标签忽略。
- 列表标签栏的数量基于**当前已加载的笔记列表**统计，不是全库统计；切换文件夹后数量会变化。
- 标签筛选与搜索互斥使用：搜索时展示搜索结果，标签栏不参与过滤。

### 3.1.5 搜索

- 后端 `search_notes`：关键词去空格为空时返回空数组；否则对 `Note_Title` 与 `Note_Content` 做 `LIKE '%keyword%'`。
- 结果排序：置顶优先，`updated_at` 倒序。
- 搜索日志按 1 秒节流，避免逐字刷屏。

## 3.2 阅读器模块

### 3.2.1 导入书籍

入口：书架页「+ 导入书籍」（`BookshelfView.vue`）。

1. 使用 Tauri dialog 选择单个文件，过滤器为 `epub/pdf/mobi/txt`。
2. 调用 `import_book_file`：
   - 校验扩展名，仅接受四种格式；
   - 标题取源文件名（不含扩展名）；
   - 复制到 `<data>/books/<uuid>.<ext>`，避免同名覆盖；
   - 返回新路径、格式、标题。
3. 前端识别总页数/章节数：
   - PDF：`pdfjs-dist` 读取 `numPages`；
   - EPUB：`epubjs` 读取 `spine.length`，8 秒超时；
   - TXT：读取字节、解码后按章节标题规则计数；无匹配章节记为 1；
   - MOBI：0；
   - 任意失败记录警告并返回 0。
4. 调用 `create_book` 入库，作者为空，初始状态 `unread`、`currentPage = 0`。
5. 失败弹窗 `导入失败: ...`，按钮恢复可用。

### 3.2.2 书架

- 数据来源 `list_books`，按 `updated_at` 倒序。
- 状态筛选：全部 / 在读 / 未读 / 已读完。
- 卡片展示封面占位（按格式显示 📗/📕/📘/📄）、状态徽章、标题、作者（空显示「未知作者」）、进度条与进度文本：
  - 无总页数：`未开始`；
  - TXT：`第 currentPage / totalPages 章`；
  - 其他：`currentPage / totalPages 页`；
  - 百分比按 `currentPage / totalPages` 计算。
- 删除：二次确认后软删除数据库记录，并尝试删除 `<data>/books` 下的物理文件；文件删除失败只记警告（例如记录的是外部路径）。
- 监听 `mysystem:sync-completed` 刷新列表。

### 3.2.3 阅读页

入口：`/reader/book/:id`（`BookReaderView.vue`）。仅支持 `epub`、`pdf`、`txt`；`mobi` 显示「暂不支持格式」。

工具栏：

- 返回书架；
- EPUB：「目录」切换右侧/左侧目录面板，「标注」切换标注面板；
- TXT：「目录」切换章节面板；
- 书名与当前位置（EPUB 当前章节名、PDF `当前页/总页`、TXT `第 n / 总数 章`）；
- TXT：章节号输入 + 跳转（越界弹窗提示）；
- PDF：缩小/放大；
- 全局上一页/下一页按钮。

离开阅读页时重新拉取书籍列表，让书架上的进度及时更新。

#### EPUB

- 使用 `convertFileSrc` 生成 asset URL，`ePub(url)` 加载；
- 渲染模式 `flow: 'scrolled-doc'`、`spread: 'none'`；
- 阅读位置保存在 `localStorage` 键 `epub_pos_<bookId>`（CFI），不写入数据库；
- 目录来自 `book.loaded.navigation.toc`，递归展平并记录层级；
- 翻页调用 `rendition.prev()/next()`；
- 选中文字弹出颜色气泡（黄 `#FFEB3B`、绿 `#A5D6A7`、蓝 `#90CAF9`、粉 `#F48FB1`），点击颜色创建标注并立即高亮；
- 已有标注从 `list_annotations` 读取，解析 `position` JSON 中的 `cfi` 后渲染高亮；
- 标注面板点击条目跳转到 CFI，删除标注时移除高亮；
- 保存标注后派发 `mysystem:annotation-added` 刷新面板。

超时保护：`book.ready` 15s、恢复位置 8s、首次渲染 15s、目录 5s；失败显示错误遮罩。

#### PDF

- 使用 `pdfjs-dist`，worker 通过 `?url` 引入；cMap 从 unpkg 加载（需要网络，否则部分中文 PDF 可能缺字）；
- 单页 Canvas 渲染，按 `devicePixelRatio` 提升清晰度；
- 缩放范围 0.5–3.0，步长 0.2；
- 打开时恢复数据库中的 `currentPage`；
- 翻页/跳页后 500ms 防抖保存进度；卸载时立即保存；
- 到达最后一页时 `readingStatus = finished`，否则 `reading`；
- 键盘：←/PageUp 上一页，→/PageDown 下一页，`+`/`=` 放大，`-` 缩小。

#### TXT

- `fetch(assetUrl)` 读取字节，编码识别顺序：
  1. UTF-16 LE/BE BOM；
  2. UTF-8 BOM；
  3. 严格 UTF-8；
  4. GBK；
  5. 回退 UTF-8。
- 章节识别：行去空格后以「第」开头，匹配 `第[一二三四五六七八九十百千万零〇\d]+[章节回]`，长度小于 40；首个章节前的内容归为「序章」。
- 章节号作为 `currentPage`（1 起）；打开时恢复；
- 翻章/跳章后 500ms 防抖保存；卸载时立即保存；
- 到达最后一章状态为 `finished`；
- 正文按非空行拆段，段首缩进 2em，最大宽度 780px；
- 键盘 ←/PageUp、→/PageDown 翻章（输入框内不响应）。

#### 标注（当前仅 EPUB）

- 数据模型：文本、备注（当前导入未填）、页码（EPUB 记 0）、`position`（JSON，含 `cfi`）、颜色。
- 面板按创建时间顺序列出，显示颜色条、文本、备注；点击条目跳转；删除需确认。
- PDF/TXT 暂无选中标注功能。

## 3.3 设置与同步

入口：`/settings`。页面由同步设置、同步日志、日志查看器、关于四部分组成。

### 3.3.1 同步设置

- **接收同步请求**开关：
  - 开启：写入配置 `sync.receive.enabled = true`，启动 UDP 发现监听与 HTTP 服务端；
  - 关闭：写入 `false`，停止两个服务。
- **设备名称**：点击「修改」弹出输入框，保存到 `device.name`；空白或未变化不保存。
- **设备 ID**：从 `localStorage` 的 `mysystem_device_id` 获取，首次生成 UUID v4。
- 状态指示：开关开启显示绿点「可被其他设备发现」。
- 首次进入设置页时读取配置；若已开启会自动恢复服务（模块级 `initialized` 标志保证只执行一次）。

### 3.3.2 扫描与连接

- 点「扫描局域网设备」广播 UDP `discover`，等待 2 秒收集 `announce`；自动过滤自己、按设备 ID 去重。
- 设备卡片显示名称、平台、IP，以及「连接」「同步」按钮。
- 「连接」调用 `GET /api/info`（3 秒超时），成功后显示「已就绪 · 协议版本 1」，同步按钮才可用。
- 未发现设备显示「未发现已打开同步开关的设备」。

### 3.3.3 手动同步

前提：已连接目标设备。

1. 本机 `get_sync_payload(deviceId, deviceName)` 读取全量文档 + 笔记；
2. `exchange_sync_data(ip, payload)` 发送到对方；对方先合并，再返回自己的全量数据；
3. 本机 `apply_local_payload(serverPayload)` 合并对方数据；
4. 展示「新增 X，合并 Y，拒绝 Z」，写入同步日志，并派发 `mysystem:sync-completed` 让各模块刷新。

合并规则：

- 本地无该文档：插入文档及其笔记；
- 对方的 `updated_at` 更新：覆盖标题、删除标记、版本、设备 ID，并替换笔记内容；
- 时间相等或本地更新：拒绝，保留本地。

同步日志：

- 界面保留最近 50 条（时间、级别、消息），可清空；
- 同时通过 `logger` 写入系统日志，前缀 `[Sync]`。

### 3.3.4 日志查看

- 日志文件列表来自 `<data>/log`，按修改时间倒序；
- 选择文件后读取最后 512KB，按级别（全部/INFO/WARN/ERROR/DEBUG）过滤；
- 显示日志目录绝对路径，可刷新；
- 覆盖式面板，点击关闭返回设置页。

## 3.4 平台首页

`/`（`HomeView.vue`）：显示已加载模块名称、版本与数量，主要用于诊断。启动时 `App.vue` 会自动跳到第一个模块，因此通常不会停留在首页。

## 3.5 全局交互约定

- **二次确认**：所有删除操作调用 `platform/services/dialog.ts` 的 `confirmAction`，底层使用 Tauri dialog 插件。不要使用 `window.confirm`：在 Tauri WebView 中点击取消仍可能返回 `true`。
- **加载与错误**：阅读器用覆盖层显示「加载中...」与错误；导入失败用 `alert`；列表用空状态。
- **日志**：业务结果写模块 store；高频操作节流（搜索 1s、自动保存 5s、翻页保存日志按每次进度变化但由防抖控制频率）。
- **桌面/移动差异**：Android 隐藏 `FolderTree` 与 `TagFilter`，使用底部 Tab；其余功能一致。
