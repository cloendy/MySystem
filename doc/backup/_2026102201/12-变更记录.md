# 12 变更记录

本文件记录版本级变更与重要实现调整。详细代码历史以 Git 为准。

## 未发布 — `feature.202611.v001`

### 文档

- 新增 `doc/` 文档中心：项目概述、系统架构、功能设计、UI 设计、数据库设计、数据结构、开发 API、开发指南、部署配置、测试排错、已知偏差与路线图。
- 原始设计文档移动到 `doc/personal-system-design-v2.md`。
- `CLAUDE.md` 同步更新设计文档路径与文档索引。

### 数据与文件夹

- 文件夹表由 `folders` 改为 `Note_Folders`：
  - 四位补零编号 `Folder_ID`，最大 9999；
  - 显式 `Folder_Level`（0 为默认「未命名」，1–3 为用户层级）；
  - `Folder_Parent_ID` / `Folder_Parent_Name` / `Folder_Order`；
  - 唯一索引保证同级不重名。
- 启动时自动迁移旧 `folders` 表并删除旧表，同步重映射 `notes.folder_id`。
- 默认文件夹改为固定编号 `0001 / 未命名 / 层级 0 / 排序 0`；不可改名、删除或添加子文件夹。
- 删除文件夹时：
  - 笔记移动到父文件夹（根级删除时进入「未命名」）；
  - 子文件夹上移一级并追加排序；
  - 子文件夹重名时改名为 `原名_folder_被删文件夹名`，必要时追加序号；
  - 后代层级递归调整。
- 文件夹重命名改为内联输入框，Enter/失焦提交，Esc 取消，空名/同名不修改。

### 交互与修复

- 新增统一确认弹窗 `platform/services/dialog.ts`，替换所有 `window.confirm`，修复“点击取消仍删除”的问题。
- 删除文件夹后重新拉取文件夹列表，修复子文件夹在 UI 中错误显示到根级的问题。
- 笔记列表/编辑页删除、书架删除、标注删除全部使用统一确认。
- 文件夹新建输入框支持同级重名校验、错误行内展示、父级自动展开。

### 其他

- 新增 `doc/` 下的开发文档与 API 清单。
- 代码注释、日志、UI 文案统一中文。

## 0.1.0 — 初始可用版本

### 平台

- Tauri 2 + Vue 3 + TypeScript + Vite 工程骨架。
- 平台/模块分层：`src/platform` 与 `src/modules`。
- 模块自动发现（`import.meta.glob`）、路由自动注册（`/{moduleId}` 前缀）。
- Windows `AppShell` 与 Android `MobileShell` 双外壳。
- 统一数据目录 `<应用根>/data`：`mydata.db`、`books/`、`log/`。
- 统一日志服务：Rust `log_*!` 宏 + 前端 `logger`，按天分文件，设置页可查看。
- 全局 UI 点击日志与路由切换日志。

### 记事本

- 笔记 CRUD、软删除、置顶、标题/内容搜索。
- Markdown/纯文本双模式编辑（CodeMirror 6 + marked 预览），自动保存。
- 嵌套文件夹（最多 3 层）、内联新建/重命名、删除上移。
- 标签增删、标签筛选与计数。
- 笔记移动菜单。

### 阅读器

- EPUB/PDF/TXT 阅读；MOBI 可导入但暂不支持阅读。
- EPUB 目录、CFI 位置记忆、选中高亮标注、标注面板。
- PDF 分页渲染、缩放、进度保存与恢复。
- TXT 编码识别、章节解析、目录、跳章、进度保存。
- 书架导入、状态筛选、进度展示、删除。

### 同步

- UDP 54321 设备发现（`MYSYSTEM_V1`）。
- HTTP 54322 握手与全量数据交换。
- 按 `updated_at` 合并 `documents` + `notes`。
- 设置页同步开关、设备名称、扫描、连接、手动同步、同步日志。
- 同步完成后通过 `mysystem:sync-completed` 刷新各模块。

### 数据

- 统一基表 `documents` + 扩展表 `notes`、`books`、`annotations`。
- `sync_operations`、`sync_state`、`known_devices`、`app_config` 建表。
- `app_config` 保存同步开关与设备名称。
