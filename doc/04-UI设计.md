# 04 UI 设计

## 4.1 设计原则

- **简洁、低饱和**：深蓝灰主色 `#2c3e50`，浅灰背景，避免大面积强色块。
- **信息密度适中**：桌面以列表/双栏为主；移动端单列 + 底部 Tab。
- **操作就地完成**：文件夹新建/重命名使用内联输入框，笔记更多操作使用浮动菜单，减少弹窗层级。
- **危险操作必须确认**：统一使用 Tauri 原生确认框。
- **状态可见**：保存状态、同步状态、阅读进度、加载/空/错误状态都有明确反馈。

| 用途 | 色值 | 使用位置 |
|---|---|---|
| 主色 | `#2c3e50` | 顶栏、主按钮、激活态、选中标签 |
| 主色 hover | `#34495e` | 主按钮悬停、同步按钮悬停 |
| 主色 active | `#233140` | 主按钮按下 |
| 危险色 | `#c0392b` | 删除按钮、错误文案、错误边框 |
| 成功色 | `#27ae60` | 已读完徽章、同步绿点 |
| 正文 | `#333` | 主要内容 |
| 次要文字 | `#666` / `#888` | 说明、元信息 |
| 弱文字 | `#999` / `#aaa` / `#bbb` | 空状态、占位符 |
| 页面背景 | `#fff` | 内容区 |
| 面板背景 | `#fafafa` / `#f5f5f5` | 工具栏、侧栏、设置区 |
| 边框 | `#e0e0e0` / `#d0d0d0` | 分隔线、输入框 |
| 标签底色 | `#eaf1f8` | 标签 chip |
| 标签文字 | `#5a7fa0` | 标签 chip |
| 选中行 | `#e0e8f0` | 导航/文件夹选中 |
| 悬停行 | `#ececec` / `#f0f2f4` | 树节点、菜单项 |

### 字体

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

- 页面标题：20–24px，600；
- 顶栏 Logo：16px，600；
- 移动端顶栏标题：18px，600；
- 正文/列表：13–14px；
- 辅助信息：11–12px，`#888`；
- TXT 正文：16px，行高 1.9，段首缩进 2em，最大宽度 780px。

### 尺寸与间距

- 桌面顶栏 48px，侧栏 200px，状态栏 24px；
- 移动端顶栏/底栏 56px，适配 `env(safe-area-inset-top/bottom)`；
- 工具栏最小高度 52px，内边距 `10px 16px`；
- 页面内容内边距 20–24px；
- 按钮最小高度 32px，圆角 4px；
- 卡片/列表项圆角 6–8px，间距 8–16px；
- 侧边面板宽 200–260px。

### 阴影与动效

- 卡片悬停：`translateY(-2px)` + `0 4px 12px rgba(0,0,0,0.08)`；
- 浮动菜单：`0 6px 18px rgba(0,0,0,0.14)`；
- 选中气泡：`0 4px 12px rgba(0,0,0,0.15)`；
- 过渡时长 0.15–0.2s，只用于背景、颜色、位移、宽度。

## 4.3 桌面外壳（AppShell）

```
┌──────────────────────────────────────────────────────────────┐
│ MySystem              [ 搜索...（禁用） ]       同步: 未连接   │  48px
├──────────────┬───────────────────────────────────────────────┤
│ 记事本        │                                               │
│ 阅读器        │              模块内容（RouterView）            │
│              │                                               │
│ ⚙️ 设置       │                                               │
├──────────────┴───────────────────────────────────────────────┤
│ 就绪                                                          │  24px
└──────────────────────────────────────────────────────────────┘
```

- 顶栏：左侧 Logo；中间搜索框（当前 `disabled`，全局搜索未接入）；右侧同步状态（静态「同步: 未连接」）。
- 左侧导航：模块按钮按 `order` 排序（记事本 10、阅读器 20）；激活项左侧 3px 主色条、浅蓝背景、加粗。
- 设置固定在侧栏底部，带分隔线。
- 内容区独立滚动；状态栏固定「就绪」。
- 点击导航跳转 `/{moduleId}/`。

## 4.4 移动外壳（MobileShell）

```
┌──────────────────────────────┐
│ 模块名 / 设置          🔍(禁用) │  56px + 安全区
├──────────────────────────────┤
│                              │
│        模块内容               │
│                              │
├──────────────────────────────┤
│  📝记事本   📖阅读器   ⚙️设置  │  56px + 安全区
└──────────────────────────────┘
```

- 顶栏标题取 `route.meta.moduleName`，设置页显示「设置」；
- 底部 Tab 使用模块 `icon` 与 `name`，激活变主色；
- 内容区启用 `-webkit-overflow-scrolling: touch`；
- 笔记列表在 Android 上隐藏文件夹树与标签筛选，其余交互与桌面一致。

### 书架

- 网格布局：`repeat(auto-fill, minmax(180px, 1fr))`，间距 16px；
- 封面高 200px，无封面时显示格式 emoji + 格式大写；
- 右上角状态徽章：在读（主色底白字）、已读完（绿底白字）、未读（半透明白底）；
- 卡片下方：标题、作者、3px 进度条、进度文本、删除按钮。

### 设置页

- 最大宽度 640px，页面内边距 24px；
- 分区标题 + 设置行（左说明、右控件）；
- 同步开关为 48×26 圆角开关；
- 设备卡片浅灰底、1px 边框，连接/同步按钮并排；
- 同步日志与系统日志为列表/覆盖面板。

## 4.7 交互模式

### 内联编辑

用于文件夹新建与重命名：

- 输入框替换原文本/插入目标位置；
- 创建后自动聚焦、全选；
- Enter 提交，Esc 取消，失焦提交；
- 错误（重名/后端失败）在行内以红色小字显示，不关闭输入框。

### 浮动菜单（NoteMenu）

- 通过触发按钮的 `getBoundingClientRect()` 定位；
- `useFloatingMenu` 根据视口边界调整 left/top，空间不足时翻转；
- 点击外部或滚动关闭；
- 二级视图（文件夹列表）切换后重新计算位置；
- 当前文件夹项禁用。

### 确认弹窗

```ts
if (!(await confirmAction('确定删除这条笔记？', '删除笔记'))) return;
```

- 统一 warning 类型；
- 删除文件夹的文案会根据是否有父级变化，明确说明子项去向。

### 防抖与节流

| 场景 | 策略 |
|---|---|
| 笔记搜索输入 | 250ms 防抖 |
| 笔记自动保存 | 5s 空闲防抖 + 30s 强制间隔，离开/关闭前保存 |
| 笔记保存状态 | 脏检查：无修改不写库，显示「已保存」 |
| PDF/TXT 进度保存 | 500ms 防抖 + 卸载立即保存 |
| 搜索业务日志 | 1s 节流 |
| 自动保存日志 | 5s 节流 |
| UI 点击日志 | 同路由同标签 300ms 去重 |

### 键盘

| 页面 | 按键 | 行为 |
|---|---|---|
| PDF | ←/PageUp、→/PageDown | 上一页/下一页 |
| PDF | `+`/`=`、`-` | 放大/缩小 |
| TXT | ←/PageUp、→/PageDown | 上一章/下一章（输入框内不响应） |
| 阅读页 | ←、→ | 上一页/下一页（EPUB/PDF/TXT） |
| 文件夹输入框 | Enter / Esc | 提交 / 取消 |
| 标签输入框 | Enter / Esc | 添加 / 取消 |

> 已知问题：PDF/TXT 组件与阅读页父组件都绑定了方向键，可能一次按键翻两页/两章，见 [11-已知偏差与路线图.md](11-已知偏差与路线图.md)。

## 4.8 响应式与平台差异

- 平台判断在 `module-loader.ts` 的 `detectPlatform()`（userAgent 含 `android` 即为 Android）。
- 桌面：左侧导航 + 内容区 + 状态栏；笔记页显示文件夹树与标签栏。
- 移动：顶部标题 + 底部 Tab；隐藏文件夹树与标签栏；阅读页未针对侧栏做覆盖式适配，目录/标注面板会占用横向空间，属于待优化项。
- 阅读器在移动端未单独压缩工具栏，按钮较多时可能拥挤，属于待优化项。

## 4.9 样式组织

| 文件 | 内容 |
|---|---|
| `src/style.css` | 全局 reset、`html/body/#app` 高度、字体 |
| `src/styles/common.css` | 通用类：`.btn`、`.btn-primary`、`.btn-danger`、`.btn-ghost`、`.btn-icon`、`.toolbar`、`.empty-state`、`.overlay`、`.side-panel`、`.text-input`、`.tag-chip`、`.switch`、设置页样式 |
| 各组件 `<style scoped>` | 页面/组件私有布局与样式 |

新增 UI 时优先复用 `common.css` 的类，避免重复定义按钮、工具栏、空状态和遮罩。
